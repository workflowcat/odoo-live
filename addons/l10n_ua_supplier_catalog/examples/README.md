# Приклади прайсів

Вигадані постачальники і ціни для тестів і демонстрації. Кожен файл показує типовий
випадок, який профіль прайсу має прочитати:

| Файл | Постачальник | Що в ньому |
| --- | --- | --- |
| `priklad_kriplennya_2026-11.csv` | ТОВ «Приклад Кріплення» | рядки-заголовки над таблицею, ціна з ПДВ за упаковку, фасовка окремою колонкою, позиція не з класифікатора |
| `priklad_metal_2026-11.csv` | ТОВ «Приклад Метал» | ціна без ПДВ, прокат за кілограм, профільна труба за метр |
| `zrazkovyi_vahovi_2026-11.csv` | ФОП Зразковий | кріплення на вагу: ціна за кілограм болтів |

Налаштування профілів для цих файлів - у тестах `tests/test_supplier_catalog.py`.
