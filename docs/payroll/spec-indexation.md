# Індексація зарплати (Постанова 1078)

Модуль `l10n_ua_index`. Правило «Індексація» більше не потребує ручного числа щомісяця:
сума рахується з індексів споживчих цін і базового місяця працівника. Ручне число далі
працює і має пріоритет.

## Дані

`ua.cpi.index` - один рядок на місяць: рік, місяць, індекс у відсотках до попереднього місяця
(як публікує Держстат: 100,5), поле «Джерело» для посилання. Меню «Зарплата → Довідники →
Індекси споживчих цін», пункт хабу в розділі «Довідники зарплати».

Числа вносить бухгалтер. Автоматичного джерела немає: в системі немає каналу до Держстату,
якому можна довіряти без перевірки.

## Базовий місяць

Поля працівника (вкладка «Україна», група «Індексація»):

- «Базовий місяць індексації» - ставить бухгалтер, коли треба зафіксувати місяць вручну;
- «Базовий місяць (чинний)» - те, що система візьме в розрахунок;
- «Не індексувати» - вимикає індексацію для працівника.

Якщо поле порожнє, базовий місяць беремо з історії версій контракту: остання версія, де оклад
більший за попередній. Тобто підвищення окладу автоматично переносить базовий місяць, і
індексація починається спочатку.

## Розрахунок

```
наростаючий = добуток (індекс місяця / 100) за місяці від наступного за базовим до місяця листка
відсоток    = (наростаючий - 1) × 100
сума        = прожитковий мінімум для працездатних × відсоток / 100
```

Від'ємний або нульовий відсоток дає нуль. Місяці без внесеного індексу вважаємо за 100 %
(не змінюють суму); «Зведення» показує попередження «Немає індексу споживчих цін» за минулий
місяць, поки в довіднику бракує рядка.

Правило `INDEX`: якщо у листку є вхід «Індексація» з сумою, береться він; інакше - розрахована сума.

## Спрощення, які має підтвердити бухгалтер

- Індексація не ділиться пропорційно до відпрацьованого часу.
- Підвищення окладу не порівнюється із сумою індексації в грошах: базовий місяць просто
  переноситься на місяць підвищення.
- Індексується частина доходу в межах прожиткового мінімуму для працездатних осіб; інші
  складові доходу (премії, доплати) в розрахунок не входять.

## Перевірка

Еталонний сценарій 17 у `scripts/payroll_check.py`: базовий місяць липень 2026, індекс серпня
101,0, прожитковий мінімум 3 328 → індексація 33,28; нарахування 30 033,28; ПДФО -5 405,99;
ВЗ -1 501,66; ЄСВ 6 607,32; на руки 23 125,63. Решта сценаріїв має «Не індексувати», щоб числа
не змінювалися.
