# Спека: місяць, смуга кроків замість трьох колонок

Дата: 21 вересня 2026. Макет: https://claude.ai/artifact/TZck2g8Hh4SCshRctAZC8i
Модуль `l10n_ua_period`. Не комітити: перевірку і коміт робить оркестратор.

## Що не так

Вісім блоків у три колонки, і те саме сказано тричі: речення в шапці, кольорові
позначки на дев'яти кроках і перелік «Увага» з шести пунктів праворуч.

Зайве на екрані місяця:

- «Перші кроки», вісім пунктів налаштування. Це стан запуску, не робота місяця.
- Третя колонка: «Кошик друку» (є «Папери»), «Увага» (те саме, що позначки кроків),
  «Зміни місяця» (належать крокові «Перевірка змін»).
- Нумеровані кружечки 2-3-4-5 на блоках: обіцяють порядок, якого немає.
- Речення в шапці про те, що заважає закрити.
- Сіра рамка з поясненням усередині кроку.

## Рішення

```
[ шапка: Вересень 2026 · відкритий · крок 4 з 9 · до подання 06.10 ][ Закрити місяць ][ Ще ]
[ смуга місяців ]
[ три числа місяця: нараховано · до виплати · ЄСВ ]
[ смуга з дев'яти кроків, видно стан кожного, відкритий один ]
[ тіло кроку на всю ширину: що це, його документи, його рядки, що заважає ]
```

Смуга кроків замінює перелік у лівій колонці: усі дев'ять видно одразу, клік відкриває
крок. Тіло кроку займає всю ширину, третьої колонки немає.

Три числа місяця стоять у шапці, бо вони про місяць, а не про крок.

Рядок унизу кроку каже, що заважає закрити місяць, і веде до причин. Це єдине місце,
де про перешкоди сказано.

«Перші кроки» переїжджають на «Домівку» і показуються, лише доки запуск не завершено.
Тут їх немає взагалі.

Пояснення кроку лишається, але під перемикачем підказок, а не постійним текстом.

## Контракт

Наявний `ua.period.board.get_screen_data` лишається точкою входу. Змінюється форма:

```python
{
  "period": {...},                       # як було
  "totals": {"gross": .., "net": .., "esv": ..},
  "steps": [{"key", "n", "name", "mark": "ok|warn|crit|idle", "current": bool}],   # 9
  "step": {                              # відкритий крок
     "key", "name", "subtitle", "hint",
     "rows": [{"level", "text", "target", "action"}],
     "blockers": {"count": 3, "text": "Усі - на кроках 4, 5 і 8.", "target": {...}},
  },
}
```

Ключі, яких більше немає: `first_steps`, `print_basket`, `attention`, `month_changes`.
Дані з `attention` розкладаються по кроках: кожен виняток знає свій крок.

## Перевірка

`scripts/period_check.py` оновлюється, наявні пункти зберігаються за змістом:

- дев'ять кроків, рівно один `current`;
- кожен крок має позначку зі списку;
- `totals` збігаються з сумами листків місяця;
- кожен виняток потрапив рівно в один крок, жоден не загубився;
- `blockers.count` дорівнює кількості причин, що справді блокують закриття;
- `first_steps`, `print_basket`, `attention`, `month_changes` у відповіді відсутні;
- кожна ціль відкривається;
- перемикання кроку не перезавантажує місяць.
