# Зарплата для України на odoo-live

Гілка `payroll`, робоче дерево `/Users/kit/Codius/odoo-live-payroll`, локальний стенд на порту 8110, база `payroll`.
Платформа (міст, Supabase, KYC) лишається на `main`. Сюди зливаємо, коли десять еталонних сценаріїв сходяться до копійки.

## Що будуємо

Рушій: OCA `payroll` для Odoo 19 (правила як дані, розрахункові листки, пакети, категорії). Він уже працює з `hr.version`,
тобто з контрактами Odoo 19. Українська частина - наші модулі поверх нього:

| Модуль | За що відповідає |
|---|---|
| `l10n_ua_payroll_rules` | таблиця параметрів із датами (МЗП, ПМ, ПСП, ставки, максимальна база ЄСВ, святкові), структура «Україна: оклад», правила ПДФО, ВЗ, ЄСВ, ПСП, поля працівника (РНОКПП, категорія ЄСВ, основне місце або сумісник) |
| `l10n_ua_hr` | штатний розпис, накази і друковані форми П-1, П-3, П-4, повідомлення про прийняття, ЦПХ і ФОП як окремі види |
| `l10n_ua_time` | табель П-5, графіки, нічні, надурочні, вихідні, простій |
| `l10n_ua_average` | середня за Постановою 100 і за Постановою 1266, страховий стаж, частина ПФУ, резерв відпусток 471 |
| `l10n_ua_payroll_account` | проводки за підрозділами, платіжні відомості, файли зарплатних проєктів банків |
| `l10n_ua_payroll_reports` | об'єднана звітність з Д1, 4ДФ, Д5, Заява-розрахунок, 1-ПВ, розрахункові листки, перевірка XML за схемою ДПС |
| маршрути моста | подання через ЕДО, індекс Держстату, оновлення параметрів |

## Як працювати

```bash
cd /Users/kit/Codius/odoo-live-payroll
docker compose up -d                                  # стенд на http://127.0.0.1:8110, база payroll
docker compose run --rm odoo odoo -d payroll -u l10n_ua_payroll_rules --stop-after-init   # оновити модуль
python3 scripts/payroll_check.py                      # прогнати еталонні сценарії
```

Логін стенда: `admin`, пароль у `.env` (`ODOO_ADMIN_USER_PASSWORD`). Секрети не потрапляють у репозиторій.

## Правила Odoo 19, які вже коштували часу

- Групи оголошують через `res.groups.privilege` і `privilege_id`, не `category_id`.
- У пошуковому вигляді `<group>` без `expand` і `string`.
- Фільтр пошуку працює лише на збережених полях.
- Канбан-картка - `<t t-name="card">`.
- Контракт працівника - це `hr.version`; модуля `hr_contract` немає.
