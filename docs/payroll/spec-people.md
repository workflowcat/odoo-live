# Спека: екран «Люди»

Дата: 21 вересня 2026. Макет: https://claude.ai/artifact/TZck2g8Hh4SCshRctAZC8i
Модуль `l10n_ua_people`. Не комітити: перевірку і коміт робить оркестратор.

## Що не так

Чотири пункти меню («Картки працівників», «Оргструктура», «Підрозділи»,
«Штатні розписи») показують один набір фактів: хто працює, в якому підрозділі,
на якій посаді, на яку ставку і за який оклад. Щоб порівняти склад із розписом,
бухгалтер відкриває два різні екрани і рахує в голові.

## Рішення

Один екран, чотири погляди на ті самі дані, пошук над ними.

| Погляд | Що показує |
| Перелік | усі працівники рядками, пошук і фільтри |
| За підрозділами | згруповано, з підсумком осіб, ставок і фонду |
| Схема | підпорядкування, від директора вниз |
| Штатний розпис | той самий склад у формі документа |

Погляд «Штатний розпис» - не окремий документ, а поточний склад, показаний у формі
розпису: підрозділ, посада, код КП, одиниць, оклад, фонд. Кнопка «Створити розпис»
робить справжній `ua.staff.list` на дату, і далі він живе в «Паперах», як решта паперів.
Там само екран каже, чим поточний склад відрізняється від чинного розпису.

## Контракт

`ua.people` - AbstractModel, своїх даних не тримає.

### get_screen_data(view="list", search="", department=None)

```python
{
  "summary": {"people": 19, "departments": 5, "units": 21.5, "fund": 431900.0},
  "view": "list|departments|chart|staff",
  "search": "",
  "rows": [...],          # для list: {id, name, job, department, fte, wage, kind, target}
  "departments": [...],   # для departments: {id, name, people, units, fund, rows:[...], target}
  "chart": [...],         # для chart: {id, name, job, manager_id, target}
  "staff": {              # для staff
     "as_of": "21 вересня 2026",
     "lines": [{"department", "job", "kp_code", "units", "wage", "fund"}],
     "totals": {"units": 21.5, "fund": 431900.0},
     "current": {"name": "від 1 січня 2026", "target": {...}, "diff_units": 2.0, "diff_text": "..."} або None,
  },
}
```

`kind` - вид договору працівника; ЦПХ і ФОП у цей екран не входять (правило Лани
2026-09-16, уже зашите в доменах наявних дій).

### open_target(target) - як у `ua.home`.

### run_action("create_staff_list") - створює `ua.staff.list` на сьогодні і відкриває його.

## Меню

- новий пункт «Люди» першим у розділі «Працівники», дія - цей екран;
- прибрати пункти «Картки працівників», «Оргструктура», «Підрозділи», «Штатні розписи»
  (самі дії лишаються, бо на них ведуть цілі з інших екранів; ховаємо лише пункти меню);
- решта розділу без змін, військовий облік не чіпаємо.

## Перевірка

`scripts/people_check.py`, база payroll:

- дія `ua_people` і пункт «Люди» видимі звичайному користувачу;
- чотири погляди відповідають без помилок, кожен дає свій ключ;
- у переліку немає ЦПХ і ФОП;
- підсумок збігається з сумою по підрозділах (особи, одиниці, фонд);
- «Штатний розпис» дає ті самі одиниці й фонд, що й «За підрозділами»;
- пошук звужує перелік і не падає на порожньому результаті;
- кожна ціль відкривається через `open_target`;
- `create_staff_list` створює документ і відкриває його (перевіряти лише на копії бази);
- пунктів «Картки працівників», «Оргструктура», «Підрозділи», «Штатні розписи»
  у меню більше немає.
