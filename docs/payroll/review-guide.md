# Зарплата на Odoo 19: посібник для перевірки

Стенд для бухгалтера. Дата: 9 вересня 2026. Компанія, люди і цифри вигадані.

## Вхід

- Посилання: https://odoo-demo.botpartners.workers.dev (кнопка «Відкрити стенд»).
- Логін: `lana`. Пароль надіслано окремо.
- Права: кадри, зарплата, бухоблік (менеджер). Дані можна змінювати. Базу можна скинути до вихідного стану.

## Що є на стенді

- Odoo 19 Community, модуль OCA payroll без змін, українські правила у 5 власних модулях.
- 13 еталонних працівників за серпень 2026. Пакет «Зарплата за серпень 2026», усі листки підтверджені, проводки створені.
- Довідник параметрів: МЗП 8 647, ПМ 3 328, ПДФО 18 %, ВЗ 5 %, ЄСВ 22 % і 8,41 %, ПСП 1 664 і поріг 4 660, макс. база 172 940.
- Правила: оклад за відпрацьовані дні, ЦПХ, премія, ПДФО з ПСП, ВЗ, аліменти, аванс, ЄСВ з мінімальним внеском і максимальною базою.
- Середня зарплата: відпускні (Постанова 100), лікарняні за рахунок роботодавця і ПФУ (Постанова 1266), компенсація відпустки.
- Друковані форми: розрахунковий листок, розрахунково-платіжна відомість.
- Проводки: 92/661, 661/6411, 661/6415, 92/651, 378/661, 661/6851. Журнал «Зарплата».
- Об'єднана звітність: XML за формою J0500111 v11 (наказ Мінфіну 243/2026) з Д1, 4ДФ і Д5. Файли перевірені за офіційними XSD.
- Банк: імпорт виписки CSV, правила звірки для 661, 6411, 6415, 651, 6851. Зразок виписки завантажено.

## Порядок перевірки

1. Співробітники → відкрити картку «Еталон 1». Вкладка «Україна»: РНОКПП, вид договору, основне місце, ставка, ПСП, категорія ЄСВ, стаж, наказ, код КП.
2. Зарплата → Пакети розрахункових листків → «Зарплата за серпень 2026». Відкрити будь-який листок. Перевірити рядки: нарахування, утримання, ЄСВ.
3. У листку: кнопка «Друк» → «Розрахунковий листок». У пакеті: «Друк» → «Розрахунково-платіжна відомість».
4. Співробітники → «Аванс за місяць». Місяць 8, відсоток 50. Кнопка «Розрахувати аванс» діє лише на чернетки. На стенді всі листки серпня підтверджені, тому створіть новий пакет за вересень і повторіть.
5. Співробітники → «Об'єднана звітність». Рік 2026, місяць 8, номер 1, Д1, 4ДФ, Д5 увімкнені. «Сформувати». Файли з'являються у вкладенні. Відкрийте XML у FreeZvit або M.E.Doc через імпорт.
6. Бухоблік → Журнали → «Зарплата». Проводки за кожним листком. Перевірити суми і рахунки.
7. Бухоблік → Банк (поточний рахунок) → Виписки. Зразок за серпень. Кнопка «Звірити»: Odoo пропонує рахунок за призначенням платежу.
8. Зауваження: у листку внизу кнопка «Надіслати повідомлення». Пишіть там. Ми бачимо всі повідомлення.

## Питання до бухгалтера

1. Аванс: 50 % окладу чи оплата фактично відпрацьованих днів першої половини місяця? Дати виплат 20-е і 6-е підтвердити.
2. Лікарняний: розрахунковий період 12 місяців, виключення днів без збереження зарплати. Перевірити середньоденну.
3. Відпускні: ділити на календарні дні мінус святкові. Під час воєнного стану свят немає. Підтвердити.
4. Д1: сценарій звільнення, рядок компенсації і категорія застрахованої особи. Сценарій лікарняного: рядок з категорією 29.
5. 4ДФ: ознаки доходу 101 (зарплата), 102 (ЦПХ), 140 (аліменти). Підтвердити.
6. Д5: підстава припинення трудових відносин і код КП. Формат наказу у графі 16.
7. Проводки: рахунок витрат 92 типово. Потрібен розподіл на 23, 91, 93 за підрозділами? Поле є у картці підрозділу.
8. Форма виписки банку: надішліть реальний експорт із вашого банку без персональних даних. Ми зробимо шаблон під нього.

## Що ще не зроблено

- Повідомлення про прийняття (J3001001), табель, накази, штатний розпис.
- ФОП-підрядники у 4ДФ (ознака 157).
- Додаткові дні відпустки за інвалідністю.
- Резерв відпусток (471), Заява-розрахунок до ПФУ.
- Надсилання XML у кабінет ДПС напряму через API (спроєктовано, потрібен КЕП).
- Банківські API (ПриватБанк, Monobank) замість файлів (спроєктовано).
