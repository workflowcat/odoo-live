# Зарплата на Odoo 19: посібник для перевірки

Стенд для бухгалтера. Дата: 9 вересня 2026. Компанія ТОВ «Ясен Меблі», люди і цифри вигадані.

## Вхід

- Посилання: https://odoo-demo.botpartners.workers.dev (кнопка «Відкрити стенд»).
- Логін: `lana`. Пароль надіслано окремо.
- Права: кадри, зарплата, бухоблік (менеджер). Дані можна змінювати. Базу можна скинути до вихідного стану.

Кожен випадок окремий: повний оклад, 0,5 і 0,25 ставки, сумісник, ЦПХ, ПСП базова і на дітей, інвалідність, відпустка, лікарняний, без збереження, аліменти, звільнення з компенсацією, прийняття 17-го, повторне прийняття (дві версії однієї картки), максимальна база ЄСВ, премії, ФОП-підрядник (4ДФ 157), декретна відпустка 126 днів (допомога ПФУ, Д1 категорія 42).
- Пакети листків: липень 2026 закрито, серпень 2026 закрито, вересень 2026 у чернетках. У липні і серпні аванс 20-го (майстер) і остаточний розрахунок.

- Резерв відпусток: 9,6 % від фонду плюс ЄСВ на резерв, проводка Дт витрати Кт 471 (параметр, 0 вимикає).

- Повідомлення про прийняття (J3001005, редакція 2025): майстер на працівниках, XML валідний за схемою ДПС.
- Проводки в журналі «Зарплата»: Дт 23/91/92/93 Кт 661; Дт 661 Кт 6411, 6415, 6851; Дт 23/91/92/93 Кт 651; Дт 378 Кт 661.
- Об'єднана звітність за серпень: XML J0500111 v11 з Д1, 4ДФ і Д5, перевірені за офіційними XSD. Файли у вкладеннях майстра «Об'єднана звітність».

## Порядок перевірки

1. Меню: усе для зарплати в додатку «Зарплата» (Розрахунок, Звітність, Кадрові документи, Довідники); кадри у «Співробітники»; облік у «Бухоблік». Співробітники → будь-яка картка. Вкладки: Робоча інформація, Приватна інформація, Україна (РНОКПП, вид договору, основне місце, ставка, ПСП, категорія ЄСВ, стаж, наказ, код КП, Д5). Картка Ткачука: дві версії контракту (звільнений 31.05, прийнятий знову 17.08).
2. Зарплата → Пакети розрахункових листків → «Зарплата за серпень 2026». Відкрити листок. Перевірити: відпрацьовані дні, нарахування, утримання, аванс, до виплати, ЄСВ.
3. У листку: «Друк» → «Розрахунковий листок». У пакеті: «Друк» → «Розрахунково-платіжна відомість».
4. Зарплата → Розрахунок → «Аванс за місяць»: місяць 9, відсоток 50 → «Створити». Відкривається авансова відомість: рядки можна правити, далі «Затвердити» (аванс потрапляє у вересневі листки) і «Друк». «Повернути в чернетку» прибирає аванс із листків.
5. Зарплата → Звітність → «Об'єднана звітність»: рік 2026, місяць 8, номер 1, Д1, 4ДФ, Д5 → «Сформувати». XML у вкладенні. Відкрити у FreeZvit або M.E.Doc через імпорт.
6. Бухоблік → Журнали → «Зарплата»: проводки за кожним листком. Перевірити рахунки витрат за підрозділами.
7. Бухоблік → Банк (поточний рахунок) → Виписки → серпень. Кнопка «Звірити»: Odoo пропонує рахунок за призначенням платежу (661, 6411, 6415, 651, 6851).
8. Кадрові документи: у картці працівника вкладка «Контракт» → «Друк» → наказ про прийняття або звільнення; у відпустці «Друк» → наказ про відпустку. Зарплата → Кадрові документи: «Штатний розпис» і «Табель (П-5)» створюють документ з рядками: перевірте, виправте, «Затвердити», «Друк». Списки «Штатні розписи» і «Табелі» поруч. У пакеті листків кнопка «Заява-розрахунок ПФУ» створює документ; список у Зарплата → Звітність.
9. Зауваження: у листку внизу «Надіслати повідомлення». Пишіть там. Ми бачимо всі повідомлення.

## Питання до бухгалтера

1. Аванс: 50 % окладу за відпрацьовані дні 1-15 чи інша база? Дати 20-е і 6-е підтвердити.
2. Лікарняний: розрахунковий період 12 місяців, виключення днів без збереження. Перевірити середньоденну Ковальчука.
3. Відпускні: ділити на календарні дні мінус святкові. Під час воєнного стану свят немає. Перевірити Мельничука.
4. Д1: рядок компенсації при звільненні, категорія застрахованої особи; лікарняний рядок з категорією 29.
5. 4ДФ: ознаки доходу 101 (зарплата), 102 (ЦПХ), 140 (аліменти). Підтвердити.
6. Д5: підстава припинення трудових відносин і код КП. Формат наказу у графі 16.
7. Проводки: рахунки витрат за підрозділами 23, 91, 92, 93. Підтвердити або змінити у картці підрозділу. Резерв відпусток 9,6 %: нараховувати чи вимкнути?
9. Декретні: допомога нарахована одразу за 126 днів у серпні; максимальна база ЄСВ застосована до всієї суми, а не помісячно. Підтвердити або дати методику.
10. ФОП: у 4ДФ ознака 157, у лічильниках «працювало за ЦПД» не рахуємо. Підтвердити.
8. Форма виписки банку: надішліть реальний експорт із вашого банку без персональних даних. Ми зробимо шаблон під нього.

## Що ще не зроблено

- Відрядження і добові, лікарняні по догляду за дитиною, відпустка по догляду до 3 років.
- Індексація рахується вручну (вхід «Індексація»); автоматичний розрахунок за базовим місяцем не зроблено.
- Надсилання XML у кабінет ДПС напряму через API (спроєктовано, потрібен КЕП).
- Банківські API (ПриватБанк, Monobank) замість файлів (спроєктовано).
- Табель будується з графіка і відпусток; облік фактичних годин (понаднормові, нічні) не ведеться.
