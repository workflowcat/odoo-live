# Еталонні сценарії розрахунку зарплати

Бухгалтер рахує кожен сценарій вручну і підтверджує колонки «очікувано». Розрахунок Odoo має зійтися до копійки.
Параметри 2026 року: МЗП 8 647, ПМ для працездатних 3 328, ПСП базова 1 664, поріг ПСП 4 660, ПДФО 18 %, ВЗ 5 %, ЄСВ 22 % (8,41 % для працівників з інвалідністю),
