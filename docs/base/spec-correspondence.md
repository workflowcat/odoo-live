# l10n_ua_correspondence: реєстрація кореспонденції

Модуль `addons/l10n_ua_correspondence`. Залежність: `mail`. Тести: тег `ua_correspondence`.

Аналог журналів вхідних і вихідних документів у 1С «Документообіг» і BAS. Оборонні підприємства
отримують від замовника документи з грифом «Для службового користування» і мусять вести їх окремо.

## Що є

| Що | Як |
| --- | --- |
| Номер | послідовність напрямку, з початку року, без пропусків: `Вх/2026/0001`, `Вих/2026/0001` |
| Кореспондент | контрагент, їхній номер і дата, вид документа, як надійшов, кількість аркушів |
| Контроль | виконавець і строк: виконавець отримує завдання з цим строком; перенесли строк - перенеслось завдання |
| Прострочені | відкриті документи зі строком у минулому; фільтр «Прострочені», червоний рядок у списку |
| Відповідь | кнопка «Відповісти» на вхідному відкриває вихідний із кореспондентом і змістом; реєстрація відповіді закриває вхідний |
| Журнал | друк вибраних документів: вхідні й вихідні окремо, ДСК окремо з грифом |
| API | `register_rows(direction, date_from, date_to, restricted=False)` - рядки журналу для інтерфейсу |

Зареєстрований документ не видаляють, а скасовують: номер у журналі лишається.

## ДСК

Типова інструкція про порядок обліку документів зі службовою інформацією (постанова КМУ від
2016-10-19 № 736): документи ДСК реєструються окремо, до номера додається позначка ДСК.

- Окрема нумерація: `Вх/2026/0001-ДСК`.
- Гриф ставиться лише під час реєстрації (від нього залежить номер) і не знімається.
- Бачить і реєструє ДСК лише група «Кореспонденція з допуском до ДСК». Без неї документа немає ні в
  списках, ні в пошуку, ні у вкладеннях і повідомленнях (вони перевіряють доступ до документа).
- Виконавець документа ДСК мусить мати допуск. Відповідь на ДСК теж ДСК.

## Питання до діловода

- Індекс справи за номенклатурою (`01-12/345`) поки не ведеться: номер лише за напрямком і роком.
- Облік примірників ДСК (кому видано, повернення, знищення) - наступний крок, якщо замовник вимагає.
