# Показова база: що в ній є і як її зібрати

Стан на 2026-10-08, гілка `show/ua-polish`. Мета - база, яку можна показати кільком людям
одразу: голий Odoo 19, українські слова, дані в кожному розділі, жодного діалогу з меню.

## Зібрати

```
DEMO_DB=show DEMO_PORT=8133 scripts/demo_server.sh reset      # ~10 хв
export DEMO_DB=show ODOO_URL=http://127.0.0.1:8133
python3 scripts/demo_business.py     # «Ясен Меблі» і «Ясен Логістика»
python3 scripts/demo_aerosich.py     # «АероСіч»
python3 scripts/demo_show.py         # те, що лишалось порожнім
python3 scripts/demo_fill.py         # поля форм: ОЗ, контрагенти, номенклатура, замовлення
python3 scripts/demo_world_check.py  # контрольні рівності історії (лише читає)
python3 scripts/show_fill.py         # які поля форм порожні в усіх записах
python3 scripts/show_audit.py        # огляд усіх пунктів меню
AUDIT_LANG=en_US python3 scripts/show_audit.py   # те саме англійською: кирилиці бути не має
python3 scripts/show_e2e.py          # прохід меню і друку за логінами
```

Після зміни модуля чи перекладу без перезбирання:
`DEMO_DB=show DEMO_PORT=8133 scripts/show_upgrade.sh модуль1,модуль2` (з `--i18n-overwrite`).

## Розділи верхнього меню

| Розділ | Чиє | Що показувати |
| --- | --- | --- |
| Бухоблік | ядро + OCA + `l10n_ua_*` | проводки, банк і звірка, каса, основні засоби, ПДВ, податок на прибуток, ОСВ і регістри, Ф1/Ф2 |
| Зарплата | `l10n_ua_*` над OCA payroll | місяці, листки, авансові відомості, заяви ПФУ, відомості на перерахування, параметри |
| Кадри | `l10n_ua_*` над `hr` | картки, прийняття, накази, штатний розпис, табелі, військовий облік |
| Звітність | `l10n_ua_reporting`, `l10n_ua_vat`, `l10n_ua_finrep` | звіти ДПС за період, ПДВ, фінзвітність |
| Продажі, Закупівлі, Склад, Виробництво, CRM | ядро + тонкі `l10n_ua_*` | замовлення, запити на закупівлю, вхідні рахунки, зони й полиці, наряди, собівартість |
| Контакти, KYC | ядро, `bp_kyc`, `l10n_ua_partner_edr` | контрагенти з ЄДР, справи перевірки |
| Працівники, Відпустки, Календар, Обговорення, Зведення | ядро | рідні екрани, лише перекладені |

Службові розділи («Тест», порожній корінь payroll, дубль запитів на закупівлю,
«Відстеження посилань») видно тільки в режимі розробника.

## Як улаштовано слова

Усе в одному місці - `addons/l10n_ua_navigation`:

- `hooks.py`: `MENU_RENAMES` (назви пунктів за xml id), `ROOT_SEQUENCE` (порядок розділів),
  `DEVELOPER_ONLY_MENUS`, `PAGE_ACTIONS` і `PAGE_TITLES` (сторінки замість діалогів).
- `data/terms_uk.json`:
  - `fill` - англійський рядок без перекладу -> українською (ставиться, лише якщо порожньо);
  - `force` - те саме, але завжди;
  - `by_model` - слово лише в поданнях однієї моделі;
  - `replace` - заміна слова в уже перекладеному тексті ядра (регулярний вираз Postgres):
    «Співробітник» -> «Працівник», «Партнер» -> «Контрагент», «Замовлення на купівлю» ->
    «Замовлення постачальнику», «Робочі замовлення» -> «Наряди», «Елементи журналу» ->
    «Рядки проводок», «Контракт» -> «Договір», «Відділ» -> «Підрозділ».
- Застосовується на встановлення і на кожне оновлення модуля (`data/apply.xml`).
- OCA: `addons/<модуль>/i18n/uk.po`, перелік у `addons/OCA_translations.md`.

Норма слів - `docs/payroll/words.md` і словник «Лад»; огляд ERP Kit і ephemeral -
`docs/archive/erpkit-ephemeral-survey-2026-10-08.md`.

## Сторінка замість діалогу

Звіти OCA (ОСВ, головна книга, журнал проводок, незакриті розрахунки, заборгованість за
строками, звіт з ПДВ), нарахування амортизації, звіт про ОЗ і імпорт виписки відкриваються
сторінкою: кнопки майстра стоять у шапці, період заповнений з початку року. Механізм -
`models/ua_page_wizard.py` (домішка, файли OCA не змінені).

## Перевірки

| Скрипт | Що доводить |
| --- | --- |
| `show_audit.py` | кожен пункт меню має дію-сторінку, подання будуються, список не порожній, рядки українською; з `AUDIT_LANG=en_US` - рядки англійською (слова з `l10n_ua_navigation/data/terms_en.json`) |
| `show_e2e.py` | під кожним логіном кожен пункт меню відкривається з даними; кожен друкований звіт рендериться |
| `layers_check.py`, `words_check.py`, `contract_check.py` | шари, норма слів, договір `docs/api` |

Числа на 2026-10-08 (база `show`): 466 пунктів меню адміністратора, 7 зауважень (усі в
«Налаштуваннях» ядра), англійських рядків у поданнях було 1217, стало 122; `show_e2e.py` -
5 логінів, 0 помилок, 68 друкованих форм.

Історія компанії з січня 2025 року (люди, зарплата, закриття місяців, підкладені помилки) -
`docs/base/demo-world.md`; акторський склад і календар подій - `scripts/demo_world/`.

Після нічної роботи 2026-10-08: історія на 21 місяць, 357 проведених листків, проводки
«Ясен Меблів» Дт 89 950 158,75 = Кт; полів, порожніх у всіх записах, було 377, стало 195

Аудит безпеки: `~/Codius/security-audits/odoo-live-show/run-1/` - 14 підтверджених знахідок

в асистент працівника і спільний токен моста для staging і prod.

## Відомі прогалини

- Серпень 2026 не закривається: два навмисно незведені рядки виписки. Сторінка місяця тепер
  каже про це сама (перешкода «банк»).
- KYC: рішення у справі неможливе без моста (`bp_kyc/models/kyc_case.py`, `_decide`).
- Вхідні рахунки: перевірки рахуються лише в гілці з AI; заведений руками рахунок їх не отримує.
- ФОП, пільги і компенсуючі ПЗ з ПДВ порожні: у меблевої ТОВ чесного прикладу немає.
- Коди професій заведені з пам'яті ДК 003:2010, без звірки з сервісом profkod.
- На сервері (`deploy/`) параметр `report.url` не задається - PDF можуть виходити без стилів.
