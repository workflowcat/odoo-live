# Питання до бухгалтера: одним списком

Лано, ми будуємо облікову систему на Odoo: зарплата, відпустки, банк, ПДВ, каса, основні
засоби, фінзвітність, первинка, ФОП. Більшість правил уже закладені й перевірені розрахунком,
але частина місць читається двояко, і ми не хочемо вирішувати це за вас. Нижче - усі такі
місця в одному списку, без повторів; «(впливає на суми)» означає, що від відповіді змінюються
гроші. Від вас потрібне одне: у рядку «Відповідь:» написати «так» або своє число чи варіант.
Числа в прикладах - серпень 2026 року. Станом на 2026-09-22.
