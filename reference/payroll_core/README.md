# payroll_core - незалежна перевірка

Другий, окремий розрахунок української зарплати. Чистий Python, стандартна бібліотека,
без Odoo і без встановлення пакетів. Рушієм лишається Odoo; цей пакет існує тільки щоб
рахувати ті самі сценарії другим шляхом і показувати, де два шляхи розходяться.

Сенс простий. Тести Odoo перевіряють, що Odoo рахує так, як Odoo рахував учора. Це не
перевірка правильності. Тут формули виведені окремо, з закону, і звіряються з тим самим
єдиним файлом очікуваних чисел. Збіг - слабкий, але реальний доказ. Розбіжність - привід
подивитися, хто саме помиляється.

## Запуск

```
python3 -m reference.payroll_core.tests
```

З кореня репозиторію. Друкує таблицю: номер сценарію, статус, і для розбіжностей -
код рядка, число еталона і своє. Повертає 1, якщо є хоч одна розбіжність.

## Де числа

Очікуваних чисел у пакеті немає. Єдине джерело - `addons/l10n_ua_payroll_tests/golden/scenarios.json`:
той самий файл читають тести Odoo. Розійтися тихо два боки не можуть.

## Один набір правил

Правила лежать у `data/rules-ua.json` як вирази. Другої копії немає: python-список
`RULES` у `calc.py`, який дублював ті самі формули, видалено. Хто хоче змінити правило,
міняє JSON.

## Що всередині

| Файл | Що робить |
| --- | --- |
| `params.py` | законодавчі числа з датою початку дії |
| `data/params-ua.json` | ставки, межі, мінімалка - з посиланням на норму |
| `data/cpi-ua.json` | індекс споживчих цін Держстату для індексації |
| `data/rules-ua.json` | єдиний набір правил розрахунку |
| `model.py` | дані листка: працівник, час, відсутності, введення, історія |
| `calendar_ua.py` | норма робочих днів: п'ятиденка, свят під воєнним станом немає |
| `average.py` | середня за Постановами 100 і 1266 |
| `indexation.py` | індексація за Порядком 1078 |
| `calc.py` | рушій: числа листка, помісячний ЄСВ, виконання правил |
| `dsl.py` | безпечний обчислювач виразів |
| `moves.py` | проводки за Інструкцією 291 |
| `scenarios.py` | переклад сценарію з JSON у листок; без жодного очікуваного числа |
| `tests/__main__.py` | прогін усіх сценаріїв і таблиця розбіжностей |
| `dps/` | XML ДПС; у прогін сценаріїв не входить, бо потребує lxml |

## Чого тут немає

Обліку, банку, кадрових документів, інтерфейсу. І ніяких чисел, підігнаних під Odoo:
чесна розбіжність корисніша за тихий збіг.
